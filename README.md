# Equipo 00 · Rocket Tec Sinaloa 2026

Landing page estática para publicar en GitHub Pages.

## Publicación rápida

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y la carpeta `assets` manteniendo su estructura.
3. En **Settings → Pages**, selecciona `Deploy from a branch`, la rama `main` y la carpeta `/root`.
4. Guarda y abre la URL que GitHub Pages mostrará.

## Personalización

- La fecha objetivo está en `index.html`, en la constante `target`.
- El sonido se genera con Web Audio API; no requiere archivos externos.
- El navegador exige un clic inicial para activar audio.
- El diseño funciona sin frameworks ni instalación de dependencias.

## Identidad visual

Se incluyen los recursos originales del equipo en `assets/`: logo principal, logo horizontal y póster de identidad visual.
